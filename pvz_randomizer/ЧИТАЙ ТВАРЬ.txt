ЧИТАЙ ТВАРЬ.txt — если не прочитаете, вас будут проклинать боги рандома.

ЧТО ЭТО
-------
Скрипт рандомит колоду (деку) для Plants vs Zombies (Steam/GOTY, Windows).
На каждом уровне плашка "Choose Your Seeds" пропускается, а в слоты
встают случайные (но привязанные к сидy) растения — как на мини-играх x-5.

КАК ЗАПУСТИТЬ (3 шага, всё)
----------------------------
1. Поставь Python 3 с python.org (при установке ОБЯЗАТЕЛЬНО тикни
   "Add Python to PATH").
2. Запусти скрипт ОТ АДМИНИСТРАТОРА:
   - самый простой способ: двойной клик по файлу run_as_admin.bat
     (сам попросит UAC-разрешение);
   - вручную: "Пуск" -> напиши cmd -> правый клик -> "Запуск от имени
     администратора" -> перейди в папку (cd C:\путь\к\pvz_randomizer) ->
     python pvz_randomizer.py
3. Дальше просто меню на русском: выбери режим, уровень — и играй.
   Скрипт сам найдёт процесс игры (PlantsVsZombies.exe / Plants.exe) и будет подсовывать деку на каждом уровне.

РЕЖИМЫ
------
1 — возможный: дека всегда проходима (есть солнце, бойцы, кувшинка на воде,
    горшок на крыше). Никаких софтлоков, можно стримить.
2 — технически возможный: рандому похуй. Может выдать 6 тыкв и ноль солнца.
    Есть возможность софтлока — это фича, не баг.
3 — сид: пишешь число. Без минуса = режим 1, с минусом (например -12345) =
    режим 2. Один и тот же сид = одно и то же прохождение (как в Майнкрафте),
    так что ролик можно переснять по сидy.

ГДЕ ВЗЯТЬ ОФФСЕТЫ ЕСЛИ "НЕ РАБОТА / НИЧЕГО НЕ ПРОИСХОДИТ"
----------------------------------------------------------
Скрипт без Cheat Engine, но адреса в файле pvz_memory.py могут не совпасть
с твоей версией игры. Проверенные значения для Steam GOTY (PlantsVsZombies.exe):

  база:            [[0x008C0000]+0x9F790]      = структура TheApp
  текущий уровень: [[[0x008C0000]+0x9F790]+0x8C]        (int, id уровня)
  SeedPacket:      [[[0x008C0000]+0x9F790]+0x40]
  кол-во слотов:   [SeedPacket+0x28]           (int)
  id растений:     [SeedPacket+0x2C+i*4]       (int, i = 0..9)

Если у тебя другая версия — открой Cheat Engine один раз, найди "Number of
seed slots", ПКМ -> Find what accesses, и обнови эти 4 строки в pvz_memory.py.
Больше трогать ничего не надо.

ПЛАН А (рекомендую для видео): мод PvZ Community Project (LPM)
---------------------------------------------------------------
Это легальный мод, который сам умеет запускать уровни с готовой колодой БЕЗ
всякой возни с памятью. Скачивается с GitHub (Lawn-Mod / PvZ-Community-Launcher).
Если он запущен — скрипт сам его увидит и передаст деку через него.

ЕСЛИ ВСЁ РАВНО "НИЧЕГО НЕ ПРОИСХОДИТ"
--------------------------------------
* Скрипт и игра должны быть запущены с одинаковым уровнем прав (оба от админа
  или оба без — иначе Windows запретит читать память).
* Игра должна быть УЖЕ запущена и стоять на экране/уровне, когда ты запускаешь
  автопилот (Enter вместо уровня в меню).
* Окно игры должно быть в фокусе в момент старта уровня.
* Steam-версия и "репаки" имеют разные адреса — см. раздел про оффсеты.
